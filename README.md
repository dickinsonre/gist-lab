## 🌈 Overview

**Gist Lab** is a lightweight, interactive web app that surfaces and organizes all of my public GitHub Gists in one clean, browsable dashboard — think of it as a personal snippet library for quick reference to code, notes, and experiments.

## 🚀 Live Demo

> 🔗 **[View Gist Lab Live →](https://dickinsonre.github.io/gist-lab/)**

## 🛠️ Features

- 📋 **Unified Gist Feed** — pulls and displays all public gists in a single view
- 🔎 **Search & Filter** — quickly locate a snippet by keyword, language, or date
- 🎨 **Syntax Highlighting** — clean, readable code previews
- ⚡ **Zero Backend** — pure client-side `index.html`, deployed via GitHub Pages
- 📱 **Responsive Layout** — works across desktop and mobile

## 📦 Tech Stack

| Layer | Technology |
|---|---|
| 🧱 Structure | HTML5 |
| 🎨 Styling | CSS3 |
| ⚙️ Logic | JavaScript (Vanilla / Fetch API) |
| 🌐 Hosting | GitHub Pages |

## 🧩 Getting Started

```bash
git clone https://github.com/dickinsonre/gist-lab.git
cd gist-lab
open index.html
```

No build step, no dependencies — just open and go. 🎉
